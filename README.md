# ReCut

Вертикальні шорти з етерів: пошук моментів, субтитри, плашки й вебкамера, рендер і черга публікацій у TikTok та YouTube через Buffer.

Інтерфейс — українською або англійською (перемикач у шапці). Програма повністю безкоштовна. Якщо вона тобі допомагає — підтримай розробку на [Patreon](https://www.patreon.com/miishanii).

## Встановлення

Завантаж **ReCut-Setup.exe** з [Releases](https://github.com/mrbear22/ReCut/releases/latest), запусти й обери теку.
Нові версії програма знаходить сама: у шапці з'являється кнопка «Оновити».

Відео — файл на диску або запис етеру Twitch: посилання `twitch.tv/videos/…`, вхід через Twitch чи назва каналу на головній.
Запис Twitch на диск не качається: для пошуку моментів береться низька якість і звук, для рендеру — лише вибрані моменти в оригіналі.
Скільки місця займає кеш і моделі, видно на головній («Місце на диску»), там же його можна очистити.

Перед рендером програма питає, куди зберегти шорти (спершу пропонує `renders\<проєкт>\` у теці програми). Проєкти, моделі й налаштування — у `data\`.

Важке завантажується лише коли вперше знадобиться: модель розпізнавання мови (1.6 ГБ), бібліотеки CUDA для NVIDIA (1.3 ГБ),
локальний ШІ для пошуку моментів за змістом мови (~5 ГБ, встановлюється в «Місце на диску» на головній). Усе працює локально й безкоштовно.

## Клавіші на таймлайні

| | |
|---|---|
| `Ctrl` + тягни | область аналізу |
| тягни по порожньому місцю | лассо: вибрати кілька кліпів і реплік (Del — видалити, ПКМ — перенести репліки до спікера) |
| `Shift` + тягни | новий кліп; у рядку реплік — нова репліка |
| `Alt` + тягни по кліпу | вирізати шматок (ПКМ — повернути) |
| правий `Alt` + клік по кліпу | петля: шорт почнеться звідси, початок кліпу піде в кінець |
| правий `Alt` + тягни по кліпу | хук: цей шматок повториться на самому початку шорту |
| `G` | глобальний у цьому кліпі чи репліці / свої налаштування (рядком під елементом зліва) |
| `Ctrl+B` / `Ctrl+I` / `Ctrl+U` | форматування виділених слів репліки |
| `Ctrl+C` / `Ctrl+V` / `Ctrl+D` | копіювати / вставити / дублювати |
| `Del` | видалити вибране |
| ПКМ | меню дій з кліпом, реплікою, елементом, областю чи рамкою |
| `Shift` / `Ctrl` у кадруванні | тримати пропорції / вимкнути прилипання |

## Розробка

Запуск із сорсів (Python 3.12+ і ffmpeg з libass у PATH; дані в `app\data`, рендери в `app\renders`, оновлення вимкнені):

    pip install numpy pillow "opencv-python-headless<5" faster-whisper
    python app/shorts.py

Збірка (Git Bash, Inno Setup 6):

    ./build.sh        →  dist/ReCut-Setup.exe

Новий реліз: підняти `VERSION` в `app/recut/update.py`, закомітити, зібрати й викласти:

    gh release create v1.2.3 dist/ReCut-Setup.exe

Програма порівнює свій тег з новим релізом через GitHub. Змінились лише файли в `app/` — завантажує тільки їх;
змінились `build.sh`, `installer.iss` чи `launcher/` — тихо ставить новий інсталятор.

- `app/shorts.py` — точка входу; код програми — пакет `app/recut/`:
  `server` і `api` — HTTP і маршрути; `projects`, `media` (ffmpeg), `analysis` (моменти), `stt` (розпізнавання мови), `render`, `art` (елементи-картинки),
  `twitch` (записи Twitch через yt-dlp, кеш шматків), `net` і `libs` (завантаження), `publishing` і `buffer` (Buffer), `system` (вікно, діалоги), `update`
- `app/ui.html`, `app/styles.css`, `app/js/` — інтерфейс (`core`, `home`, `panels`, `editor`, `selection`, `preview`, `timeline`, `menus`, `render`);
  `app/i18n.js` — англійська; `app/publish.js` — публікація
- `RECUT_DATA=<тека> python app/shorts.py --no-window` — сервер з окремою текою даних (розробка, тести)
- `cloudflare/worker.js` — сховище відео для Buffer (Cloudflare R2)
- `launcher/` — `ReCut.exe`; `installer.iss` — інсталятор
